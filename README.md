# AI Customer Support

An AI-powered customer support web application designed to demonstrate
AI integration, REST API development, backend engineering, and responsive
web application development.

## Overview

This project demonstrates how an AI-powered customer support system
can be integrated into a web application through a RESTful backend API.

## Features

- AI-powered customer support
- REST API integration
- Intelligent response workflow
- Responsive web interface
- Backend API with FastAPI
- Error handling
- Automated API testing
- Docker-ready deployment

## Technology Stack

- Python
- FastAPI
- REST API
- HTML5
- CSS3
- JavaScript
- AI / LLM
- Docker
- Pytest
